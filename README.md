# visual-fidelity

把设计稿或参考页面还原成前端实现，并用像素、几何、归因三层证据给出可复核的判决。

这个仓库提供一个可安装的 Agent Skill：`visual-fidelity/`。

## 它解决什么

"照着这张图做出来"这类任务，最常见的失败不是做不出来，而是**做完了没人能证明它像**。这个 skill 的做法是把"像不像"变成可执行的数字：

- **像素**：渲染截图逐像素比对，输出结构性差异占比与热区；
- **几何**：两侧各量一遍元素盒，按角色配对，任一 1px 漂移即判不通过；
- **归因**：把差异像素分配到具体 DOM 节点，指出是哪个元素在拖后腿。

判决由工具给出，不由自我评价给出。缺证据一律 `UNVERIFIED`。

## 两种参考形态

| 形态 | 证据 | 判决上限 |
|---|---|---|
| 图源（只有一张图） | 像素 + 图像取证得到的几何 | `READY WITH SUBSTITUTIONS` |
| 页源（可渲染） | 上述 + computed style + 行为 | `READY` |

图源模式拿不到样式证据，但差异确实集中在字形时，可以显式声明证据换取 `READY WITH DECLARED FLOOR`——豁免留痕，不是阈值放水。

## 实测收敛

- 页源：同一页面的一个组件，18.67% → **0.136%**
- 图源：只有一张截图，53.4% → **4.155%**（其中 4.155% 已确认为字形栅格地板）

## 安装与使用

见 [`visual-fidelity/README.md`](visual-fidelity/README.md)。

```bash
cd visual-fidelity
pnpm add playwright-core
node test/verdict.test.mjs      # 离线单测
```

Windows / macOS / Linux 通用，浏览器由 Node 自己拉起。

## 设计原则

1. **规则必须可执行**：每条规则要么有代码、要么有测试、要么是明确的人工步骤，三样都没有的规则不写。
2. **缺证据不下结论**：没有渲染对比就只能是 `UNVERIFIED`。
3. **地板是解释不是豁免**：字形栅格差异会被标注并给出三个数字，要豁免必须显式声明证据。
4. **不读参考站点的源码**：读了就从"还原"变成"复制"，而复制检验不出还原能力。
